# @hustle-ring/art — art sets

Spec: [`docs/ART_SPEC.md`](../../docs/ART_SPEC.md) (section 17). Decisions: ADR-0051…0053.

## What ships

The default set (`sets/default/`) is drawn by a deterministic generator in `tools/art-default/`
(modern cartoon, no text, one drawing per catalog slot; `pnpm art:draw`). Each generated file
carries the marker `<!-- art:default generated by tools/art-default -->`. New catalog slots (a
pack that adds a location) start as wireframes (`pnpm art:placeholders`) until `pnpm art:draw` or
an artist fills them.

## Drawing a slot by hand

1. Run `pnpm art:check --report` to see which slots are drawn.
2. Open the wireframe in `sets/default/files/` (for example `building.bank.svg`). Keep its
   `viewBox`: the size is fixed per slot (17.3). The red cross marks the anchor (bottom centre
   for buildings, hosts and avatars).
3. Replace the file with your drawing and **remove the `<!-- art:placeholder -->` or
   `<!-- art:default … -->` comment**. Neither generator overwrites a file without its marker, so
   hand-drawn art is safe from `pnpm art:placeholders` and `pnpm art:draw`.
4. Avatars: paint recolourable areas in the key colours `#FF00FF` (primary) and `#00FFFF`
   (secondary). They are swapped for the player's colour at runtime (17.4).
5. Run `pnpm art:check`. It rejects scripts, event handlers, external references, `<image>`,
   namespaced editor elements (export as plain SVG), files over 60 kB and wrong viewBox sizes.

Rules: modern cartoon style, no text baked into art (names and speech are drawn by the UI), and
nothing from the 1991 original (PRD 2.6).

## Your own art packs

Players can import a `.zip` (`manifest.json` + `files/*.svg`, `extends: "default"` implied) in
Settings → Art packs while the scene UI is on. Only the keys a pack defines are replaced; the rest
come from the default set. The same validator runs with the user limits (256 kB a file, 4 MB and
400 entries a pack). See `docs/ART_SPEC.md` §17.6.

## Commands

- `pnpm art:placeholders` — create or refresh wireframes for every slot without drawn art.
- `pnpm art:draw` — (re)draw every wireframe and every earlier generator output with
  `tools/art-default`; hand-drawn files are kept.
- `pnpm art:check [--report]` — validate every set in `sets/` (part of `pnpm verify`).
